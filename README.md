# Лабораторная работа: базовые типы данных и конструкции Python

Учебный проект, в котором решены 11 практических заданий на закрепление
базовых типов данных Python: числа, строки, списки, кортежи, множества
и словари. Логика каждого файла инкапсулирована в функции, поэтому модули
можно безопасно импортировать — код не выполняется автоматически при
загрузке. Запуск любого задания доступен через консольное меню `main.py`,
функциональность покрыта автоматическими тестами на pytest.

## Структура проекта

```
python_basics_lab/
├── main.py                  # верхнеуровневый модуль: консольное меню запуска заданий
├── 00_distance.py           # задание 0: словарь словарей расстояний между городами
├── 01_circle.py             # задание 1: площадь круга и проверка точки на вхождение
├── 02_operations.py         # задание 2: знаки операций между числами 1 2 3 4 5
├── 03_favorite_movies.py    # задание 3: выбор фильмов срезами строки
├── 04_my_family.py          # задание 4: рост членов семьи (списки)
├── 05_zoo.py                # задание 5: операции со списком животных в зоопарке
├── 06_songs_list.py         # задание 6: время звучания песен (список и словарь)
├── 07_secret.py             # задание 7: расшифровка секретного сообщения срезами
├── 08_garden.py             # задание 8: цветы сада и луга (множества)
├── 09_shopping.py           # задание 9: два магазина с минимальными ценами (словари)
├── 10_store.py              # задание 10: количество и стоимость товаров на складе
├── tests/                   # автоматические тесты на pytest
│   ├── test_00_distance.py
│   ├── ...
│   └── test_main.py         # тесты консольного меню
├── pytest.ini               # настройка запуска тестов
├── requirements.txt         # зависимости проекта
├── README.md                # этот файл
└── .gitignore               # файлы, не попадающие в систему контроля версий
```

## Требования

- Python 3.8 или новее
- pytest 7.0 или новее (только для тестов)

## Установка

Клонировать репозиторий и установить зависимости (рекомендуется
виртуальное окружение):

```bash
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows

pip install -r requirements.txt
```

## Запуск заданий

Главный способ — консольное меню. Оно выводит список всех заданий,
запускает выбранное по номеру и завершает работу по команде `q`:

```bash
python main.py
```

Пример работы меню:

```
================================================================
  ЛАБОРАТОРНАЯ РАБОТА: базовые типы данных и конструкции Python
================================================================
   0. Расстояния между городами (словари)
   1. Площадь круга и точка в круге (числа)
   ...
  10. Товары на складе (словари)
================================================================
   q - выход из программы
Введите номер задания (q - выход): 1
```

Каждое задание можно запустить и по отдельности — файлы остаются
самостоятельными скриптами:

```bash
python 00_distance.py
python 01_circle.py
```

## Запуск тестов

Тесты проверяют вычисленные значения каждого задания (площадь круга,
суммарное время песен, расшифрованную фразу, множества цветов, итоги
склада и т.д.), вывод `main()` каждого модуля и работу консольного меню:

```bash
pytest            # весь набор (43 теста)
pytest -v         # подробный вывод
pytest tests/test_05_zoo.py   # тесты одного задания
```

## Как устроена инкапсуляция

В каждом файле задания вычисления оформлены отдельными функциями,
которые возвращают результат (без вывода на экран), а печать вынесена
в функцию `main()`. Вызов `main()` выполняется только при прямом запуске
файла благодаря конструкции:

```python
if __name__ == "__main__":
    main()
```

Поэтому `import 01_circle` (или подключение через
`importlib.import_module('01_distance')` в меню) не приводит к выполнению
решения — модуль лишь предоставляет свои функции и данные.
